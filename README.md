## Project Description
SheLoo is a smart, interactive map that helps women discover nearby public toilets, ranked by safety, hygiene, and overall experience—guiding them to the safest, most reliable options in real time.

---

## Problem Statement
Access to clean and secure public sanitation remains a major challenge for women in India. Existing maps often focus only on location, ignoring safety, cleanliness, lighting, and crowd levels—leaving women vulnerable, especially after dark.

---

## Solution
SheLoo transforms public sanitation into a data-driven, safe, and user-friendly experience. It combines toilet locations from OpenStreetMap with crowdsourced facility ratings and dynamic safety heuristics (traffic, nearby landmarks, and time-of-day risk), providing a ranked, interactive map.

---

## Technical Details

**Technologies Used:**
- **Languages:** JavaScript, HTML, CSS
- **Libraries/Frameworks:** Leaflet.js, OpenStreetMap API
- **Tools:** VS Code, Git

---

## Features
- **Intelligent Toilet Discovery:** Locate nearby public toilets quickly with interactive map pins.
- **Safety-First Ranking:** Toilets ranked dynamically by lighting, crowd, area safety, and time-of-day.
- **Facility Ratings & Feedback:** View and submit cleanliness, lighting, and safety ratings.
- **Guided Navigation:** Route display with estimated time and safe navigation prompts.
